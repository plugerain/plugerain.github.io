Project

GBP Store Ops Board

One board for multi-country stores' Google Business Profiles — auto issue alerts and AI review replies

ReactViteTypeScriptNode.js(Express)PrismaSQLiteClaude APIi18n
Role
Planning and data design; full-stack build with AI agents (to learn full-stack architecture)
Period
2026-09

github.com/mw44lee/gbp-dashboard

Problem

  • For global retail stores, the Google Business Profile (GBP) is the first storefront. Yet issues such as falling ratings, review spikes, closure flags and stale cover photos have to be checked store by store.
  • Reviews from many countries arrive in different languages, which makes them hard for headquarters to scan.

Solution

  • Each store's visibility and action metrics, products and reviews are on one screen.
  • Rule-based detection flags issues such as rating drops, review spikes and closures in an alert feed. Each store is rated healthy, warning or critical.
  • Reviews can be translated into any language, whatever the original.
  • AI drafts replies that follow brand guidelines.

What I did

  • Designed the conversion script that maps a real multi-country store dataset to the app schema.
  • Put the issue rules in one place (the alerts service), so the board, the alerts and future notification jobs all use the same thresholds.
  • Built the full stack (frontend, backend, database, AI integration) hands-on with an AI agent, to learn the architecture end to end.

Technology & architecture

  • Backend: Node.js, Express, Prisma and SQLite
  • Frontend: React and Vite (/api is proxied to the backend)
  • AI: translation and reply drafts run on the server through the Claude API. The key stays on the server, and the app runs end to end with mock replies if there is no key.
  • The UI language (EN/KO) and review translation (AI, cached) use separate paths.

About the data

  • Store names, addresses, ratings, review counts and operating status come from the real dataset.
  • Performance metrics such as views and clicks are simulated from ratings and review counts.
  • Products and sample reviews are placeholders.
