Project

Daisuki Japanese Study Portal

Learn lessons 12–14 of a Japanese textbook in one page — listen, speak, write and test

HTMLJavaScriptWeb Speech APIMediaRecorderlocalStorageGitHub Pages
Role
Learning design and feature planning; built with AI agents (vibe coding)
Period
2026-11 ~

Problem

  • The vocabulary, short sentences, homework and test prep for my Japanese class textbook (Daisuki, Book 1) are scattered across paper and audio files.
  • Studying alone, it is hard to check pronunciation, record and compare my own voice, and separate what I have memorized from what I have not.

Solution

  • One-page portal: lessons 12, 13 and 14 (104 sentences, 150 words) each have a word list, short expressions, grammar patterns, homework and a mock exam in one place.
  • Listening: every sentence has native audio (textbook audio) and read-aloud, with playback speed 0.8x / 1.0x / 1.2x.
  • Speaking: record ten sentences in a row and play them back as one clip.
  • Memorizing: flash cards, word quiz, word-piece puzzle, typing practice and a review mode for unlearned items. Kanji show their readings (furigana).
  • Writing and homework: write and translate the reading passages, then print them to hand in.
  • Progress: each user's progress is saved in the browser.

What I did

  • Designed the per-lesson structure and the review flow (listen → repeat → memorize → test) to match the class schedule.
  • Organized the textbook content into words, sentences and patterns, and defined the quiz and mock-exam formats.
  • Built the screens and features with AI agents and published the site on GitHub Pages.

Tech and architecture

  • Runs as a single HTML file with no server (audio is embedded). Publishing it to GitHub Pages makes it live immediately.
  • Read-aloud uses the browser's speech synthesis (Web Speech API); recording uses MediaRecorder.
  • Progress and user profiles are kept in browser storage (localStorage).
