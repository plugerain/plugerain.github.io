Project

다이스키 일본어 학습 포털

Daisuki Japanese Study Portal

교재 12~14과의 단어·문장·숙제·모의고사를 한 페이지에서 듣고 말하고 쓰며 익히기

HTMLJavaScriptWeb Speech APIMediaRecorderlocalStorageGitHub Pages
역할
학습 설계·기능 기획, AI 에이전트와 함께 바이브 코딩으로 구현
기간
2026-11 ~

문제

  • 일본어 수업 교재(다이스키 상권)의 단어, 단문, 숙제, 시험 대비가 종이와 음원 파일로 흩어져 있다.
  • 혼자 복습할 때 발음을 확인하고, 내 발음을 녹음해 비교하고, 외운 것과 못 외운 것을 나눠 보기 어렵다.

해결

  • 한 페이지 포털: 12과·13과·14과(단문 104문장, 단어 150개)를 과별로 나눠 단어장, 단문 표현, 문형 정리, 숙제, 실전 모의고사를 한곳에 모았다.
  • 듣기: 문장마다 원어민 음성(교재 음원)과 읽어 주기 기능을 쓰고, 재생 속도(0.8x·1.0x·1.2x)를 고를 수 있다.
  • 말하기: 10문장을 차례로 녹음하고 하나로 합쳐 들어 볼 수 있다.
  • 외우기: 카드 암기, 단어 퀴즈, 단어 조각 맞추기, 직접 타이핑, 미암기 복습 모드. 한자 위에 읽는 법(후리가나)을 표시한다.
  • 쓰기·숙제: '읽어 봅시다' 지문을 쓰고 번역하고, 인쇄해 제출할 수 있다.
  • 학습 기록: 사용자별 진행 상황을 브라우저에 저장한다.

내가 한 일

  • 수업 진도에 맞춰 과별 구성과 복습 순서(듣기 → 따라 말하기 → 외우기 → 시험)를 설계했다.
  • 교재 내용을 단어·문장·문형 단위로 정리하고, 퀴즈와 모의고사 문항 형식을 정했다.
  • AI 에이전트와 함께 화면과 기능을 구현하고, GitHub Pages로 공개했다.

기술·구조

  • 서버 없이 HTML 파일 하나로 동작한다 (음원도 파일 안에 포함). GitHub Pages에 올리면 바로 열린다.
  • 발음 듣기는 브라우저의 음성 합성(Web Speech API), 녹음은 MediaRecorder를 쓴다.
  • 학습 기록과 사용자 구분은 브라우저 저장소(localStorage)에 둔다.

다음 계획
